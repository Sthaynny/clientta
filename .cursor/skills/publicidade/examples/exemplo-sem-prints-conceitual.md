# Exemplo — sem prints (modo conceitual)

Quando o usuário disser **sem prints** ou a pasta estiver vazia:

## O que fazer

1. Marcar entrega: `Fonte visual: identidade apenas (conceitual)`  
2. Coletar do brief: nome, cores hex, vertical, 3–5 telas **genéricas** plausíveis  
3. UI inventada alinhada ao vertical — [riqueza-mockup-ui.md](../references/riqueza-mockup-ui.md)  
4. **Não** usar dados reais, logos de bancos, PII ou claims médicos/financeiros garantidos  
5. GenerateImage sem `reference_image_paths` ou só com `logo.png` se houver  

## Telas conceituais sugeridas (finanças)

| Card | Tela genérica |
|------|----------------|
| 01 | Dashboard com totais do mês |
| 02 | Formulário “novo gasto” |
| 03 | Lista categorizada |
| 04 | Configurações / privacidade |
| 05 | Onboarding ou CTA welcome |

## Telas conceituais (agenda / serviços)

| Card | Tela genérica |
|------|----------------|
| 01 | Calendário semana |
| 02 | Novo agendamento |
| 03 | Lista de clientes |
| 04 | Notificações / lembretes |
| 05 | Página pública de agendamento |

## Aviso na entrega

> Artes conceituais — substituir por prints reais antes de publicar na loja para máxima fidelidade.
