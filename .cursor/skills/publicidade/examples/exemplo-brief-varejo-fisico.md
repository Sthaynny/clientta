# Exemplo — brief varejo físico (fictício)

Loja: **Casa & Cor** — tintas e acabamento.

| Campo | Valor |
|-------|--------|
| Objetivo | Visita à loja + conversão |
| Peça | Cartaz A3 vitrine |
| Oferta | 20% off em tintas premium até 30/11 — **só se usuário confirmar** |
| Público | Moradores num raio de 8 km |
| Identidade | `#004E89`, `#FF6B35`, letras sans bold |
| Restrição | Preço legível a 3 m |

## Estrutura do cartaz

| Zona | Conteúdo |
|------|----------|
| Topo 40% | Headline: "Parede nova até o fim de semana" |
| Meio 35% | Oferta: "20% off tintas premium" + validade |
| Base 25% | Endereço fictício exemplo · "Mostre este cartaz no caixa" |

## Flyer A5 (verso)

- Lista 3 categorias em promo  
- CTA: WhatsApp da loja (número informado pelo usuário)

## GenerateImage (se pedir arte)

- `aspect_ratio`: proporção A3 (~ `3:4` ou brief explícito)  
- Alto contraste; um preço protagonista  
- Sem foto stock genérica se puder usar produto real (foto fornecida pelo usuário em `reference_image_paths`)

Não gerar peça de varejo com desconto inventado.
