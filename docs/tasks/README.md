# Tarefas — Sextante

Visão **operacional** das tarefas do **Sextante** (`university_hub`), agrupadas por **feature** ou área transversal. Cada item traz **o que fazer**, **objetivo** e **impacto**.

## Como ler

| Pasta / arquivo | Conteúdo |
|-----------------|----------|
| [finalizadas/](finalizadas/) | Entregas **Concluídas** no app ou na documentação de produto |
| [a_fazer/](a_fazer/) | **Não iniciado**, **Em andamento**, **Bloqueado** ou **Planejado** |

Cada entrada usa o mesmo formato:

- **ID** — identificador do [mapeamento_tarefas.md](../mapeamento_tarefas.md) (ex. T-001)
- **Título** — resumo curto
- **O que fazer** — ação concreta
- **Objetivo** — por que existe
- **Impacto** — Alto / Médio / Baixo + efeito esperado
- **Feature** — link para o doc da funcionalidade, quando houver
