# Tarefas — Clientta

Visão **operacional** das tarefas do **Clientta**, agrupadas por **feature** ou área transversal.

## Como ler

| Pasta / arquivo | Conteúdo |
|-----------------|----------|
| [finalizadas/](finalizadas/) | Entregas **Concluídas** |
| [a_fazer/](a_fazer/) | **Não iniciado**, **Em andamento** ou **Planejado** |

Cada entrada usa:

- **ID** — identificador do [mapeamento_tarefas.md](../mapeamento_tarefas.md) (ex. C-101)
- **Título** — resumo curto
- **O que fazer** — ação concreta
- **Objetivo** — por que existe
- **Impacto** — Alto / Médio / Baixo
- **Feature** — link ao doc da funcionalidade
