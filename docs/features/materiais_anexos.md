# Materiais e anexos

## Resumo

Anexar links, notas longas ou referências de arquivo por disciplina ou atividade (ex.: PDF da ementa, link do classroom).

## Plano

**Pro**

### Free

- Campo de observações em texto nas aulas (já disponível).
- Sem anexos de arquivo ou galeria de links.

### Pro

- Lista de links por item; opcionalmente caminho local a arquivo escolhido pelo usuário (sem sync automático).
- Limite sugerido: até 5 anexos por aula/atividade.

## Status no app

**Planejado** — sem modelo de anexo no `ClassEntry` / `ActivityEntry` hoje.

## Dependências / notas técnicas

- Avaliar permissões de mídia no `AndroidManifest` (hoje parcialmente listadas — ver débito técnico no planejamento).
- Armazenar URIs/paths no JSON local; não enviar para nuvem.
